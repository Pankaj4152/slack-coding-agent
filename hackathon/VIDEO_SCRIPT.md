# Five-Minute Demo Script

This script will be finalized after the workflow and evaluation are implemented.

1. Explain the developer bottleneck and intended user.
2. Show the simple baseline handling one task.
3. Submit an equivalent task through Slack.
4. Show planning, clarification, implementation, and verification.
5. Show a bounded recovery from a failed check, if available.
6. Show the evidence-backed Slack report and human-reviewed pull request.
7. Compare baseline and final results.
8. Explain the most valuable change, one removed experiment, and the main failure mode.
