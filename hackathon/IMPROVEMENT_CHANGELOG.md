## Current baseline

The existing system accepts an explicit repository and task from a Slack mention, creates a GitHub issue, starts a repository workflow, handles clarification replies, and reports a pull request back to the originating Slack thread. It does not yet have a separate planner, verification agent, bounded repair loop, or hackathon evaluation harness.
